# Whale Watch

A simple terminal-based docker compose manager.

## Features

- List docker containers

## Installation
Prerequisites:
- Python 3.12 _later or earlier versions may work but not tested_
- Git

1. Clone Repository
    ```
    git clone https://github.com/Puce807/whale-watch
    ```

2. Navigate to project folder
    ```
    cd whale-watch
    ```

3. Recommended but optional:
    > Create a virtual environment
    > ```
    > python -m venv venv
    > ```
    > Activate the virtual environment
    > ```
    > venv\Scripts\activate.bat
    > ```

4. Install dependencies
    ```
   pip install -r requirements.txt
   ```

5. Run script
    ```
   python main.py 
   ```
