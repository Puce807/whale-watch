# Whale Watch CLI

A simple terminal-based docker compose manager.

## Features

- List docker containers
- Get container stats

## Installation
Prerequisites:
- Python 3.12 _later or earlier versions may work but not tested_
- Git

1. Clone Repository
    ```
    git clone https://github.com/Puce807/whale-watch
    ```

2. Navigate to project folder
    ```
    cd whale-watch
    ```

3. Recommended but optional:
    > Create a virtual environment
    > ```
    > python -m venv venv
    > ```
    > Activate the virtual environment
    > ```
    > venv\Scripts\activate.bat
    > ```

4. Run install script and follow the instructions
    ```
   python install.py
   ```
5. All Done!
    ```
   ww version
   ```
